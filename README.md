# Trainee Project

This is a full-stack project that consists of both a **Frontend** and **Backend**. The project provides a simple "Welcome" page, where the frontend is built with **HTML & CSS** and the backend is built with **Node.js** and **Express**.

---

## Prerequisites

Before running this project, ensure that you have the following installed on your machine:

- **Node.js** (with npm)
  - Download and install it from [Node.js official website](https://nodejs.org/).
- **Git**
  - Install it from [Git official website](https://git-scm.com/).

---

## VM Details Script

The project includes a shell script (`get_vm_details.sh`) that collects comprehensive VM (Virtual Machine) information.

### Usage

To run the VM details script:

```bash
./get_vm_details.sh
```

### Information Collected

The script collects the following information:
- **System Information**: Hostname, OS, kernel version, architecture
- **CPU Information**: CPU model and core count
- **Memory Information**: Total, used, and available memory
- **Disk Usage**: Filesystem usage statistics
- **Network Information**: Network interfaces and IP addresses
- **System Uptime**: How long the system has been running
- **Process Information**: Number of running processes
- **User Information**: Current user and logged-in users
- **Load Average**: System load averages
- **Docker Information**: Docker version and running containers (if available)
